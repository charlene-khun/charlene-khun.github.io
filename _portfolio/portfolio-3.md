## Project Description

Understanding rental housing trends is important for housing policymakers, real estate analysts, and city planning organizations when evaluating housing conditions and making informed decisions. However, large public housing datasets often contain missing values, inconsistent data types, and numerous property characteristics that make meaningful analysis challenging. This project addresses that problem by analyzing the **San Francisco Rent Board Housing Inventory dataset**, obtained through DataSF, to identify patterns in rental housing characteristics and explore factors associated with rental-related outcomes. The objective was to transform raw housing records into meaningful insights through exploratory data analysis and machine learning.

Using **Python, Pandas, Seaborn, Matplotlib, and scikit-learn**, my team and I performed data cleaning, exploratory data analysis, and predictive modeling. We prepared the dataset by handling missing values, standardizing data types, removing irrelevant attributes, and engineering features for analysis. We developed visualizations, including correlation heatmaps, histograms, pair plots, and geographic maps, to investigate relationships among housing characteristics. We also trained and evaluated regression models using performance metrics such as RMSE, MAE, and R². Among the models evaluated, Random Forest achieved the strongest predictive performance, and feature importance analysis helped identify characteristics that contributed most to its predictions.

The primary stakeholders for this project include **housing policy analysts, city planning departments, real estate analysts, and housing organizations** interested in understanding San Francisco's rental housing conditions. The analysis supports decisions about which property characteristics warrant further investigation, how housing patterns vary across the dataset, and which variables may be useful for predictive analysis. These findings could inform housing market research, policy discussions, and future data-driven housing studies. By combining data visualization with machine learning, the project demonstrates how publicly available housing data can be transformed into interpretable insights that support informed decision-making.

**Technologies:** Python, Pandas, Seaborn, Matplotlib, scikit-learn, Folium

**Dataset:** [San Francisco Rent Board Housing Inventory – DataSF](https://data.sfgov.org/Housing-and-Buildings/Rent-Board-Housing-Inventory/gdc7-dmcn/about_data)
