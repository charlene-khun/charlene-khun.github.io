## Project Description

As online shopping continues to grow, bookstores need reliable digital systems to manage book inventories, customer transactions, and business operations efficiently. Traditional or manually managed bookstore processes can lead to fragmented records, inconsistent inventory information, and difficulties tracking customer orders and reviews. This project addresses these challenges by developing an **Online Bookstore Database System** that provides a centralized platform for customers to browse books, place orders, and submit reviews while allowing bookstore staff to manage inventory, customer information, and transactions. The objective was to create a structured, database-driven web application that improves data organization, simplifies bookstore operations, and supports a more convenient online shopping experience.

Using **Java, Jakarta EE, JSP, HTML, CSS, JDBC, and MySQL**, my team and I developed a web application supported by a relational database for managing bookstore information. The system organizes book records, customer accounts, orders, and reviews into structured database tables, allowing information to be stored, retrieved, and managed consistently. We implemented customer-facing functionality for browsing available books, placing orders, and submitting reviews, along with administrative capabilities for maintaining book information and managing transactions. The application integrates Java-based server-side functionality with a MySQL database through JDBC and uses Apache Tomcat to run the web application. This architecture demonstrates how relational database design and web development can work together to support both customer interactions and operational workflows.

The primary stakeholders for this project include **bookstore owners, inventory managers, operations staff, and online customers** who depend on accurate and accessible bookstore information. The system supports operational decisions related to inventory management, order tracking, product availability, and customer feedback. For example, bookstore managers can use stored transaction and review data to identify frequently ordered books, monitor customer activity, and determine which inventory records may need attention. Customers benefit from a centralized platform for exploring books and managing purchases. By integrating customer-facing features with a structured relational database, the project demonstrates how database management systems can improve information consistency, reduce manual data-management challenges, and establish a foundation for future business reporting and analysis.

**Technologies:** Java, Jakarta EE, JSP, HTML, CSS, JDBC, MySQL, Apache Tomcat 11, SQL
