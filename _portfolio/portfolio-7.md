## Project Description

Social media platforms contain complex networks of interconnected pages, making it challenging for entertainment companies, marketing teams, and media analysts to understand relationships between brands and identify influential communities. Understanding these connections can provide insights into how entertainment-related content is organized and which pages occupy important positions within a network. This project addresses that challenge by analyzing a **Facebook TV show pages dataset containing over 3,000 nodes** to examine network structure, connectivity, and influence. The objective was to apply social network analysis techniques to transform complex relationship data into meaningful insights that could support entertainment marketing and media strategy.

Using **graph analysis and network visualization techniques**, my teammate and I developed a program to parse the Facebook TV show network dataset and calculate structural characteristics, including the number of nodes and edges, connected components, network diameter, and centrality measures. We also applied community detection methods to identify groups of closely connected TV show pages and created network visualizations to illustrate their relationships. These analyses helped reveal how pages are connected, which nodes occupy influential positions, and how communities are organized within the broader network. By combining graph metrics with visualization, the project made complex network relationships easier to explore and interpret.

The primary stakeholders for this project include **social media analysts, digital marketing teams, entertainment companies, and media strategists** seeking to better understand relationships among entertainment-related pages. The analysis could support decisions about which pages to prioritize for marketing outreach, which network communities may offer opportunities for cross-promotion, and which influential pages might be valuable for potential partnerships. Although the dataset represents connections between Facebook pages rather than direct evidence of audience behavior, its network structure provides a useful starting point for understanding relationships within the entertainment ecosystem. By applying centrality analysis and community detection, the project demonstrates how social network analysis can identify important connections, reveal community structures, and support more informed marketing and media research decisions.

**Technologies:** Social Network Analysis, Graph Theory, Centrality Analysis, Community Detection, Network Visualization
