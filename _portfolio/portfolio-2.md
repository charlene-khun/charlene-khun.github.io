## Project Description

Understanding the geographic distribution and progression of COVID-19 is important for public health organizations, healthcare administrators, and policymakers when evaluating the impact of the pandemic. However, analyzing large volumes of state-level COVID-19 data can be challenging when trying to identify which regions experienced the highest case counts and how infections and deaths changed over time. This project addresses that problem by developing an interactive Tableau dashboard using the New York Times COVID-19 dataset to visualize cumulative cases and deaths across U.S. states. The objective was to transform historical pandemic data into accessible visual insights that support geographic comparisons and public health analysis.

Using **Tableau**, I developed an interactive dashboard combining a geographic choropleth map with a dual-axis time-series chart. The choropleth map uses color gradients to represent cumulative COVID-19 cases across states, while the line chart tracks cumulative cases and deaths over time using separate numerical axes. I implemented interactive tooltips and bidirectional cross-filtering, allowing users to select a state to examine its historical trends or select a date to explore the geographic distribution of cases at that point in time. For example, the dashboard identifies California as having the highest cumulative case count in the dataset and highlights how case and death trends differed during the winter 2020–2021 and 2021–2022 surges.

The primary stakeholders for this project include **public health analysts, healthcare administrators, and policymakers** who need to understand historical pandemic trends and regional differences. The dashboard supports retrospective decisions about which states and time periods warrant further investigation, and it can inform discussions about healthcare preparedness, resource planning, and public health responses. By combining geographic and temporal analysis in a single interactive interface, the project demonstrates how data visualization can simplify complex public health datasets, reveal meaningful patterns, and communicate insights that support evidence-based decision-making.

**Technologies:** Tableau, Data Visualization, Geographic Analysis, Time-Series Analysis

**Dataset:** [The New York Times COVID-19 Data](https://github.com/nytimes/covid-19-data)
