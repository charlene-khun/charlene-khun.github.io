## Project Description

Online shopping platforms such as Amazon offer extensive product selections, making it difficult for consumers to identify electronics that best match their needs and preferences. Traditional product searches often require shoppers to manually compare descriptions, ratings, and customer reviews, which can be time-consuming and overwhelming. This project addresses that challenge by developing an **AI-powered Chrome extension** that uses Retrieval-Augmented Generation (RAG) and Amazon electronics review data to provide product recommendations based on natural-language user queries. The goal was to simplify product discovery and help consumers make more informed purchasing decisions by making relevant product information easier to access.

Working collaboratively with a team, we developed a recommendation system that combines an AI-based retrieval pipeline with a Chrome extension interface. The system processes Amazon electronics review and product data, retrieves relevant information based on user queries, and uses a large language model to generate recommendations. My primary contributions focused on **frontend design, extension testing, debugging, user interface improvements, and technical documentation**. I researched Chrome extension development and testing, contributed to interface design and logo integration, helped troubleshoot extension files, and collaborated on implementing light and dark mode functionality. I also prepared project documentation, setup instructions, progress reports, and presentation materials to support testing, usability, and communication of the system.

The primary stakeholders for this project include **online shoppers, e-commerce businesses, and product recommendation developers** seeking more efficient ways to discover and evaluate products. For consumers, the extension supports purchasing decisions by helping identify electronics relevant to their preferences without manually searching through large volumes of reviews. For e-commerce businesses and developers, the project demonstrates how AI-powered recommendation interfaces could improve product discovery and user engagement. By integrating information retrieval, language models, and a browser-based interface, this project illustrates how AI can transform unstructured customer review data into accessible product recommendations and support more efficient, information-driven shopping experiences.

**Technologies:** Python, JavaScript, HTML, CSS, Retrieval-Augmented Generation (RAG), Large Language Models (LLMs), Ollama, Chrome Extensions

**Dataset:** [Amazon Reviews 2023](https://amazon-reviews-2023.github.io/)
