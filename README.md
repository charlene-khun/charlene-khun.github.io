## Website Features

## Website Features

This portfolio website includes:

- **About:** Personal introduction, academic interests, and technical background.
- **Portfolio:** Project showcases with descriptions, images, technologies, and links to GitHub repositories or interactive dashboards.
- **Education:** Academic background and educational experience.
- **Resume:** Overview of education, project experience, and technical skills.
- **Responsive Design:** Website layout designed to accommodate different screen sizes.
- **Project Navigation:** Individual portfolio pages containing detailed project information.

## Website Technologies

This website is built using:

- **GitHub Pages** for hosting
- **Jekyll** for static website generation
- **Academic Pages / Minimal Mistakes** as the base website template
- **HTML, CSS, Sass, and Markdown** for customization and content

## Repository Structure

Key folders and files used to maintain the website:

| File / Directory | Description |
|---|---|
| `_config.yml` | Website configuration and profile settings |
| `_pages/` | Main website pages |
| `_portfolio/` | Individual project descriptions |
| `_includes/` | Reusable HTML components |
| `_layouts/` | Page layouts |
| `_sass/` | Theme styling and customization |
| `images/` | Portfolio images and website assets |
| `files/` | Supporting files and documents |
